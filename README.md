# Perfect Builder Invoice Software

This folder is ready to publish as a GitHub Pages website.

## Publish
1. Create a GitHub repository.
2. Upload all files/folders from this folder (not the ZIP itself).
3. Repository Settings -> Pages.
4. Under Build and deployment choose "Deploy from a branch".
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish.
7. Open the generated `https://USERNAME.github.io/REPOSITORY/` address.

The app is a PWA and can be added to the Android home screen from Chrome after it is published over HTTPS.

## Important
Invoice data is stored in the browser's local storage. It is not automatically shared between different phones/laptops. A shared cloud database would be the next upgrade.
