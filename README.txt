This is a static GitHub Pages-ready recreation based on the public perfectbuilder.uk reference page.
The content, service names, statistics, contact details, FAQ and major sections follow the public reference.

IMPORTANT:
The public reference site serves its photographic assets dynamically and the exact image file URLs were not exposed by the page text extraction available while creating this package. Therefore the photo slots use stable remote construction photos rather than pretending they are the exact originals. The logo is included locally as SVG.

To publish:
1. Upload ALL files/folders to your GitHub repository root.
2. Enable Settings → Pages → Deploy from branch → main → /root.
3. Open your GitHub Pages URL.
